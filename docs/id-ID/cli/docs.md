# `openclaw docs`

Mencari indeks dokumentasi (docs) secara langsung.

```bash
# Mencari tentang ekstensi browser
openclaw docs browser extension

# Mencari tentang konfigurasi sandbox
openclaw docs sandbox allowHostControl
```
