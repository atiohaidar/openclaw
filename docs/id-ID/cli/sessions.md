# `openclaw sessions`

Menampilkan daftar sesi percakapan yang tersimpan di sistem.

```bash
# Menampilkan semua sesi
openclaw sessions

# Menampilkan sesi yang aktif dalam 120 menit terakhir
openclaw sessions --active 120

# Output dalam format JSON
openclaw sessions --json
```
