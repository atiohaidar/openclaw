# `openclaw dashboard`

Buka UI Kontrol (Control UI) menggunakan autentikasi Anda saat ini.

```bash
# Membuka dashboard di browser default
openclaw dashboard

# Hanya mencetak URL dashboard tanpa membuka browser
openclaw dashboard --no-open
```
